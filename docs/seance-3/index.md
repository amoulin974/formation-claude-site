# Séance 3 : aller plus loin et enseigner avec

Les deux premières séances vous ont donné un usage solide de l'agent. Celle-ci ouvre deux portes : **étendre** l'outil à vos besoins, et **repenser** vos enseignements dans un monde où vos étudiants l'utilisent aussi.

## Déroulé

| Durée | Séquence | Page |
|---|---|---|
| 25 min | Étendre Claude Code : skills, sous-agents, hooks, MCP | [Extensions](extensions.md) |
| 20 min | Construire un agent minimal avec l'API | [Un agent en cent lignes](agent-api.md) |
| 20 min | Paralléliser, et faire relire du code par des agents | [Parallélisation et revue](parallele-revue.md) |
| 45 min | Atelier pédagogique | [Atelier pédagogique](atelier-pedagogique.md) |
| 10 min | Synthèse, livrable final, ressources | [Synthèse](synthese.md) |

## Objectifs

À l'issue de la séance, vous serez capable de :

1. Décrire le rôle des skills, sous-agents, serveurs MCP et hooks, et choisir le mécanisme adapté à un besoin.
2. Construire un agent minimal avec l'API et l'usage d'outils.
3. Paralléliser des tâches et organiser une revue de code par agents.
4. Analyser l'effet des agents sur ses propres TP et évaluations.
5. Concevoir une activité ou une évaluation qui porte sur le raisonnement plutôt que sur le code produit.
6. Définir un cadre d'usage de l'IA pour ses étudiants, intégrité académique comprise.

## À préparer

- Le dépôt d'exercices à jour : `git pull`. La branche `seance-3-contribution` sert pendant la revue de code.
- **Un de vos TP**, sous forme d'énoncé, pour l'atelier pédagogique.
- Pour la partie API : une clé d'API (voir [Un agent en cent lignes](agent-api.md#avant-de-commencer)). Sans clé, vous suivrez la démonstration et lirez le code.

??? note "Notes pour l'animateur"
    - La partie technique est dense : privilégier les démonstrations et garder les exercices pour l'après-séance. L'atelier pédagogique ne doit pas être rogné, c'est la séquence la plus attendue.
    - Prévoir une clé d'API de démonstration pour la partie API, avec un plafond de dépense bas.
    - Pour l'atelier, constituer des groupes de trois ou quatre, idéalement de matières différentes.
