# Prérequis et installation

## Checklist avant la séance 1

- [ ] Abonnement Claude personnel donnant accès à Claude Code
- [ ] Compte GitHub
- [ ] VS Code et l'extension Dev Containers installés
- [ ] Docker installé et démarré (ou Codespaces à défaut)
- [ ] [Dépôt d'exercices](https://github.com/amoulin974/formation-claude-exercices) cloné, Dev Container ouvert, `make test` lancé une fois
- [ ] Pour la séance 3, facultatif : une clé d'API sur la [console Claude](https://platform.claude.com), avec un plafond de dépense bas (voir [Un agent en cent lignes](../seance-3/agent-api.md#avant-de-commencer))
